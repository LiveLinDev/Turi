Turi. Escribe fn nombre(x: int) -> int y el cuerpo entre llaves. int tiene 64 bits con signo; bool contiene true o false. Los parámetros son de solo lectura. let declara una constante local; var permite cambiarla. Los literales enteros infieren int. Una sentencia por línea, sin punto y coma. return es obligatorio en todos los caminos que producen un valor, incluso si una expresión está al final. Las condiciones de if y while van sin paréntesis. La alternativa se escribe } else {. for i in 0..n excluye n. La división entera trunca hacia cero. El resto se escribe %, la igualdad ==, la conjunción && y la disyunción ||. Una firma comienza siempre por fn. Una condición abre un bloque con llave. Para modificar un contador, escribe i += 1. Usa los nombres exactos de la firma.

fn adjust(value: int, steps: int) -> int {
    var result = value
    var left = steps
    while left > 0 {
        result += 3
        left -= 1
    }
    if result == 12 {
        return 99
    }
    return result
}
