Go. Escribe func nombre(x int64) int64 y el cuerpo entre llaves. int64 tiene 64 bits con signo; bool contiene true o false. Los parámetros son copias locales modificables. const declara constantes y var declara variables; := infiere el tipo. Un entero local escrito como n := 0 infiere int: usa var n int64 = 0 si lo combinas con un parámetro int64. Termina cada sentencia con un salto de línea. return debe producir el resultado en todos los caminos. Las condiciones de if y for van sin paréntesis. La alternativa se escribe } else {. Un bucle de condición usa for condición. Un contador con i < n excluye n. La división entera trunca hacia cero. El resto es %, la igualdad ==, la conjunción && y la disyunción ||. Usa los nombres exactos de la firma.

func adjust(value int64, steps int64) int64 {
    result := value
    left := steps
    for left > 0 {
        result += 3
        left -= 1
    }
    if result == 12 {
        return 99
    }
    return result
}
