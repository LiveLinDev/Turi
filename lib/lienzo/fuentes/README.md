# Fuentes incluidas en `lienzo`

Tipografías vectoriales incluidas para carga privada por proceso en Windows mediante `AddFontResourceExW(..., FR_PRIVATE)` (`tipografia.turi`), sin instalación en el sistema ni permisos de administrador:

- **Inter 4.1** (`Inter-Regular.ttf`, `Inter-SemiBold.ttf`, `Inter-Bold.ttf`) — fuente principal de interfaz (Google Fonts / rsms).
  - Origen: <https://github.com/rsms/inter/releases/download/v4.1/Inter-4.1.zip>
  - Licencia: SIL Open Font License 1.1 ([LICENSE-Inter.txt](LICENSE-Inter.txt))
- **JetBrains Mono 2.304** (`JetBrainsMono-Regular.ttf`, `JetBrainsMono-Bold.ttf`, `JetBrainsMono-Italic.ttf`) — fuente monoespaciada de código (Google Fonts / JetBrains).
  - Origen: <https://github.com/JetBrains/JetBrainsMono/releases/download/v2.304/JetBrainsMono-2.304.zip>
  - Licencia: SIL Open Font License 1.1 ([OFL-JetBrainsMono.txt](OFL-JetBrainsMono.txt))
